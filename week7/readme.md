# 파일 시스템 구조: i-node와 데이터 블록

## 1. i-node (Index Node)
파일의 **메타데이터(정보)**와 **데이터 위치**를 저장하는 핵심 자료구조입니다.

* **저장 정보:** 파일 크기, 파일 소유자, 권한(rwx), 생성 및 수정 시간, 데이터 블록 위치, 링크 수
* **특징:** 파일을 생성하면 무조건 **하나의 i-node가 할당**됩니다.

---

## 2. 데이터 블록 (Data Block)
실제 파일의 **내용**이 담겨 있는 저장 공간입니다.

* **특징:** 내용이 없는 빈 파일이라면 데이터 블록이 할당되지 않을 수 있습니다.
* **할당 방식:** 저장할 파일의 크기가 1개 블록의 크기를 넘어가면, 필요한 용량만큼 여러 개의 데이터 블록이 추가로 할당됩니다.

---

## 3. 파일 크기에 따른 블록 할당 구조
파일 시스템은 파일 크기가 커짐에 따라 **직접 블록 → 간접 블록 → 이중 간접 블록** 순으로 확장하여 데이터를 처리합니다.

| 블록 종류 | 연결 구조 | 활용 | 접근 속도 |
| :--- | :--- | :--- | :--- |
| **직접 블록** | i-node 안에 데이터 블록 주소를 **직접 저장** | 작은 파일 저장 | **가장 빠름** |
| **간접 블록** | i-node가 **블록 주소들을 저장한 블록**을 가리킴 | 큰 파일 저장 | **느림** |
| **이중 간접 블록** | i-node가 블록 주소를 저장한 블록을 가리키고, **그 블록이 또 다른 주소 블록을 가리킴** | 매우 큰 파일 저장 | **매우 느림** |
